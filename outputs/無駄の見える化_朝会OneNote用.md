# 業務効率化／無駄の見える化　（6/18　平尾）

―――――――――――――――――――――――――――――――
## ■ 木村さんのお題（6/17 朝会）
- 業務効率化に向けて、「**無駄と思われること・結果的に無駄になったこと**」をまず見える化し、ピックアップして議論する。
- 最終的には残業削減を通じた**サステイナブルなキャリア形成**につなげたい。
- 無駄の定義（木村さん）＝「**かけた努力（労力）に対して、見合わない成果になっている状態**」。
- 木村さんの見方＝無駄につながるのは「**仕事の再現性がないこと**」。再現性のない取り組みは無駄になりやすい。

―――――――――――――――――――――――――――――――
## ■ 定義をもう少し開くと
- **成果**＝人に説明できて・通って・使われ、次に活きるアウトプット。
- 「**見合わない成果**」＝労力をかけたのに、使われない／毎回ゼロからやり直す／次に活きない状態（＝同じ労力を“二度払い”）。
- だから無駄を見極める軸＝「**再現性があるか**」。“あの人だから・その時だからできた”では、同じ労力をまた払うことになる。

―――――――――――――――――――――――――――――――
## ■ 自分ごとに落とすと：再現性がない＝「型・基盤」がなく毎回ゼロから
（毎回考える時間・属人化・手戻り・見込み違い、という形で無駄になっている）

**① 報告書**
　毎回「構成・体裁をどうしよう」と考えるのに地味に時間がかかる。人によって作りもバラバラ。
　→ 考え方（目的→現状→課題→案→根拠→…→依頼）と体裁の**型を共通で整備**し、毎回の判断をなくす。

**② SA・変更管理**　※我々の業務で特にメリットが大きい
　各段階で説明する相手（SA担当／部長／環境安全／製造現場）が違い、必要な説明も違う。毎回ゼロから組み立て、抜けも出る。
　→ 段階ごとに「**ここでは誰に何を説明するか**」を型に落として共通認識化。抜けなく速い。

**③ 企業検討会など各審査・検討会**
　審査・検討会ごとに、その都度どう説明するかを考え直している。
　→ SAと同じ考え方で、**段階・対象者ごとの説明の型**に落とす。

**④ スケジュール**
　段階は規則で決まっているが、「実際に我々がここでこれをやる」という落とし込みが各自任せで、抜け漏れや後手が出る。
　→ 規則を**“我々がやること”の共通認識（型）**に落とし、「これをやらなきゃ」が一目で分かる状態に。

**⑤ 検討（データ解析）**
　各自がバラバラにデータを集めて解析している。同じことを別々に組み直し、属人化する。
　→ ①関係タグを集約した一式　②それを引いて解析するツール（リンク紐付け）　③物性計算も“周知で問題ない”ものを誰でもパッと
　　 ——を**共通化**し、それを元にデータを組む。組織に展開すれば加速する。

**⑥ 予算シート（マテバラ前提）**
　いろんな時期に作ったものを少しずつ改良して使っており、前提が実際の決算と乖離。見込み違いで後から手戻り（仕事を産む）が起きることがある。
　→ 切り詰めてしっかり検討できる**基盤に整理**し、前提と実績を突き合わせられる状態にする。

―――――――――――――――――――――――――――――――
## ■ 対策の方向（再現性を上げる）
- 共通して言えるのは「**誰でも抜けなくできる**」状態にすること＝**型・基盤を言語化して整備する**（Excel等、形は何でもよい）。伝承だけでは続かない。
- 自分の中で閉じず、**グループ・組織に展開**すれば効きが加速する。
- ＝木村さんの言う**再現性**（“あの人だから・その時だからできた”を無くす）に直結する。残業削減はその結果。
