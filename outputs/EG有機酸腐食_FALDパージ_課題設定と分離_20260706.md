# EG濃縮系リボイラー腐食／F-ALDパージ　課題設定と分離（2026-07-06）

## 1. 課題設定（何を決める話なのか）

決めたいこと（意思決定）:
M50移行（原料水フィード 124→44 t/h）にあたり、EG濃縮系リボイラー(E-1403/1404/1405)の腐食に対して、F-ALDパージ設備をM50投資に織り込むべきか。

なぜ話がぼやけたか。この判断は性質の違う複数の主張の積み重ねの上に立っているのに、「有機酸腐食がある」から「F-ALDパージに投資」まで一足飛びに論じ、途中の主張が事実なのか推定なのか対策なのかが仕分いていなかった。

判断を支える荷重主張は3つ。混ぜずに、それぞれの確からしさを別々に扱う。
- (i) 現状のリボイラー腐食は有機酸腐食である（同定：中〜確）
- (ii) M50で腐食環境は悪化方向に変わる（方向：事実＋推定で強、定量は不可）
- (iii) F-ALDは有機酸負荷の前駆体の一部を上流で削れる（弱〜中、定量不可）

判断(iv)はこの3つ全部に乗るが、確からしさは各々違う。だから、答えの出し方（事実か／推定か）ごとに問いを分け、順に固める。順序は **現状 → 機構 → 変化 → 対策 → 判断**。前の問いの答えが次の問いの制約になる（先に事実を固める）。

---

## 2. 課題の分離（5つの問い）

### 問1　現状：いま何がどこで起きているか　【事実 / ここにM50は出さない】
- 1-1　場所：チューブ内面か／シェルか、どの塔(E-1403 / 1404 / 1405、前段 / 後段)か。＝抜管・現物所見。**未確定**。単純な熱交換器構造なので両面で腐食されうる。どちらが主かを現物で閉じる（シェル側の検討が抜けている）。
- 1-2　形態：スケール下腐食＋孔食＋局部集中か、全面均一減肉か。＝現物所見。**確定寄り**。
- 1-3　速度・時系列：いつから、何を起点に、どの速度で進んだか。＝検査記録・週報。**一部未確定**（2026.1.28週報「従来把握を大幅に上回る」が直近の起点。それ以前の立ち上がりが弱い）。
- 1-4　当時の原因理解：発生当時、不純物(有機酸)の原因は何と考えられ、どう対処されたか（触媒トラブルとの関係を含む）。＝2008年有機酸上昇トラブル・1998鹿島事例。**未確定**（木村さんが直接聞いて未回答）。

ここで作るのは「動かない事実」。後段の機構・M50・対策は、すべてこの事実と矛盾してはいけない。

### 問2　機構：なぜ腐食するのか、有機酸と言い切れるか　【推定 / 動かない事実を先に】
- 2-1　同定：他機構を除外できるか。動かない事実の対比＝〔塔本体は有機酸不検出→CO2〕vs〔リボイラーはSUS444無腐食・STB340のみ腐食→有機酸＋スケール下〕。この材質選択性が同定の主根拠。**中〜確**。CO2単独・エロージョン単独・塩化物SCC等を除外できるかを明示する（SUS444が無腐食なら塩化物SCCは外せる、等）。
- 2-2　有機酸の出どころ：(a)ALD由来＝F-ALD→ギ酸／A-ALD→酢酸（EO反応器出口CS配管で生成） (b)EG系内の熱分解由来の重質酸＝グリコール酸／乳酸／シュウ酸。どれが主に効いているか。**未確定**（分析点が少なく検出下限以下で寄与配分の根拠がない。キレート性の高いグリコール酸が主犯候補）。
- 2-3　場：なぜリボイラー蒸発ゾーンか＝水が抜けて不揮発酸が局所濃縮する場。**推定（機構）**。
- 2-4　文献の前提確認：持ち込む文献機構が本系(高水82.8%)で成立するか。高水系のSantambrogio2016は前提一致で使える。低水系のKuwait TEGは前提が違うので直接根拠にしない。

「有機酸腐食」を1枚岩にしない。(i)有機酸起因という同定（中〜確）と、(ii)どの有機酸が主か（未確定）を分ける。F-ALDの話は(ii)の一部でしかない。

### 問3　変化：M50で腐食環境はどう変わるか　【事実＋推定 / ここで初めてM50】
- 3-1【事実】変わらないもの：系への有機酸／ALD持ち込み絶対量(マスバランス)。＝**確定**。まずここを固定する（"増えるから対策"ではない）。
- 3-2【事実】変わるもの：濃度(循環水量減で×2前後)／EG側滞留時間(+63%)／STMパージ絶対量(▲36〜47%)／リボイラー基数(2→1)。＝マスバランス・蒸気バランスで**確定**。
- 3-3【推定】悪化方向か：3-2の各変化を、問2の機構(濃縮因子・滞留＝反応時間・バブリング・温度)に結ぶ。方向は悪化で言えるが定量は不可。**推定**。

「濃縮率2倍」は3-2の「濃度が2倍前後に上がる」を指す言葉。循環して溜まっていく濃縮ではない。用語を正す。

### 問4　対策：F-ALDパージは何に・どれだけ効くか　【対策】
- 4-1　効き所：F-ALDパージが下げるのは有機酸負荷のうち「ギ酸前駆体(F-ALD)」の分のみ。EG系内生成の重質酸(グリコール酸等)には効かない。効く範囲を限定する。
- 4-2　定量可能性：効果を%で言えるか→現状**不可**（検出下限以下・寄与配分の分析根拠なし）。「定量約束しない」と明言することが対策設計の一部。
- 4-3　検証手段：EG-2低水比プラントテストでC-1401〜3 BTMのpH＋有機酸(ギ酸／酢酸／グリコール酸)を実測して後追い確認する。
- 4-4　ポートフォリオ内の位置：F-ALDパージ／A-ALDパージ／リン酸Na投入／施栓改造 の中で、F-ALDは「上流の予防・保険」。単独解ではない。

### 問5　判断：投資に織り込むか　【意思決定】
- 5-1　判断基準：定量効果を前提にせず「予防・保険」として妥当か。前提＝原料水低減(M50変動費改善の柱)を毀損しないこと。
- 5-2　織り込みの粒度：F-ALD単独でなく上流対策群の一部として、プラントテスト結果で後追い検証する条件付きで織り込む。

## 3. この分離で見えること（次の宿題は限られる）

分離すると、判断に必要なのに未確定なノードは4つに絞られる。ここが実際に一次資料を当てて埋める作業。
- 1-1　腐食の場所（チューブ／シェル、塔別）を現物・抜管所見で閉じる。
- 1-3・1-4　時系列と当時の原因理解を、週報・2008トラブル・1998鹿島で事実として立てる。
- 2-2　どの有機酸が主に効くか（グリコール酸主犯候補、F-ALD由来ギ酸の重み）を、生成量と場から推定として整理する。

残り（3-1・3-2の事実、2-1の同定、問4の位置づけ、問5）は既に確定または方針が立っている。

課題は「有機酸を下げれば腐食が減るか」という漠然とした一問ではなく、上の5問に分かれる。そのうち手を動かすべきは現状(1-1／1-3／1-4)と機構の一部(2-2)。F-ALDパージの正当化は「2-2で効く前駆体の一部を、問3で悪化する環境に対し、問4で予防的に削る」という限定された主張に収れんする。
