# P-1507A/B 吸入ストレーナ 40→250メッシュ 技術評価 — 検討記録(v1)

> この記録の狙い：①会話の経緯（何を試し・どこで誤り・どう直したか）を残す ②確定事実・物性式・未確定事項を固定し、別エージェント(計算/批評)と私の共有土台にする。

## 0. 目的（この検討で評価したいこと）
C-1503塔頂の黒色異物(鉄錆)の製品DEG出荷ライン流出を抑えるため、P-1507A/B吸入ストレーナのろ網を40→250メッシュへ変更。評価する技術論点は3つ：
1. **NPSH/キャビ**：どこまで目詰まりするとキャビするか／通常運転で安全か。
2. **CV監視**：下流流量制御弁(FC-1531)開度で閉塞を監視できるか（pptxの主張の検証）。
3. **低温起動**：S/D後に冷えたDEG（高粘度）で起動・運転できるか。

## 1. 確定事実（出典つき）

### ポンプ P-1507A/B（荏原 RM17156-13, 50×40IFWM）
- 定格 9.8 m³/h・58m・2910rpm・7.5kW。**NPSHr=2.20m**（規定流量）。NPSHa=14.0m（試験）/15.97m（2014水理計算）。
- **H-Q曲線はほぼフラット**：締切58.4m、換算試験で全域60〜61m（ドループ<1m）。最小流量5.4m³/h。吸込口径52.9mm。

### ストレーナ CS-1504A/B（図面 EO-S-DEG-5001-01）
- **YACフィルター 円錐型 EWPCL-150S（補強網＋内側スクリーン）・2B・SUS304**。ろ網のみ40→250。
- 開口比 40=0.36 / 250=0.27。クリーンΔP∝1/開口比² → 差圧比1.78。
- **ろ過面積≈100cm²**（円錐側面、配管断面21.6cm²の約4.6倍）。正味開口 250≈27cm² / 40≈36cm²。
- 250メッシュ目開き≈62μm（0.061mm）。
- 現状40メッシュ実測ΔP：P&IDで**1.13 kPa**（検討の基準は2kPa）。250クリーンΔP(158.8℃)≈3.6kPa。

### C-1503（吸込源）
- 塔頂 **5.7 kPaA**（減圧、≈DEG蒸気圧で相殺）。静水頭~14m → 吸込は正圧 約0.06 MPaG（図面 0.44〜2.59 kgf/cm²G）。
- T=158.8℃（実績~160℃、谷でも瞬間150℃。20年トレンドTI1533）。

### 制御弁 LV-1512 →（2015検査停止でCAS LOOP化）→ FC-1531
- azbil **AGVB・等％(EQ%)**・1-1/2B×1B。CV台帳 Cv=**14**。※2014検討ではCv10/21の記載あり→**現行Cv値は要確定**。
- Azbil仕様(SS2-AGV200-0001 表3)：固有レンジアビリティ **Cv≥1.0 → 50:1**。
- ただし**実特性は理想等％でなく多項式**：2014 TV sizingで「開度70.3%→Cv%50.2%」「開度59%→実Cv2.63=Cv%26.3%」。理想R=50で開度から逆算するとΔPが吐出超え＝過大になる（私の誤りの主因）。
- **実ΔP（2014 IER水理計算 Flow sheet）：LV-1512 = 340 kPa @ 4.34T/H・出力59%・Cv設計10・実Cv2.63**。簡易結果シート：CV ΔP=424kPa @ 4341kg/H・出力56.8%。
- 2015設計枠：送出CV ΔP **min=50 kPa**、系の付与可能圧損=**60 kPa**（最悪＝寒候期・遠方T-615）。送出はE-1509で**約35℃に冷却**（μ~6cP）。
- DCS実績(2022-2026 日次)：FC-1531開度 中央値**34%**（運転時）、流量との相関0.88（+10%/(m³/h)）、固定流量でσ3%。**100%張付きはPV≈0のS/D時のみ＝目詰まりドリフトは検出されず**。
- FC-1535（E-1509→P-1402 リサイクル, Cv4.0）はΔP≈1.2kPaで別挙動（混同しないこと）。
- 現状FC-1531 ΔP 推定 ≈ **340〜500 kPa**（2014水理＋現流量で増、実Cv逆算で整合）。

### Aspen物性（modAspenPropData.bas / Shell EOEG datadeck v4.01, rev202606）
DEG, MW=106.122。温度TはK。**この式で計算し「Aspen物性ツールで算出」と明記する**。
- 蒸気圧 PLXANT：`ln P[Pa] = 74.55 − 10632/T − 6.8195·lnT + 9.0968E-18·T^6` （262.7–680K）
- 液粘度 MULDIP：`ln μ[Pa·s] = −125.30 + 8891/T + 16.143·lnT` （270–450K）
- 液密度 DNLDIP(DIPPR-105)：`ρ[kmol/m³] = 0.83692 / 0.26112^(1+(1−T/744.6)^0.2422)`、`×106.122 → kg/m³`（262.7–744.6K）
- 検証点：158.8℃(432.0K)→ μ≈1.16cP, ρ≈1009 kg/m³, Pvp≈5.5kPa。

## 2. 現時点の評価結論（要・批評/再計算）
1. **NPSH/キャビ**：限界ストレーナΔP = NPSHa−NPSHr = 14−2.2 = **11.8m ≈ 117 kPa**。通常運転(160℃)はクリーン3.6kPa=余力の3%で支配要因でない。約85%閉塞(開口13〜17%)で到達。
2. **CV監視**：現状ΔP_CV ≈340〜500kPa ≫ 117kPa。キャビまでにFC-1531は**+3〜5%しか開かず**、流量変動(±5〜10%, σ3%)に埋もれる → **監視の主役にできない**。主指標＝ストレーナ前後差圧の直読(vs117kPa)。FC開度は副指標。
3. **低温起動**：細目網は低Re=層流→ΔP∝μ。250クリーンΔP：50℃~34kPa / 25℃~92kPa / 20℃~116kPa(≈余力)。→ 冷態(~20–25℃)起動はキャビ懸念。対策：~50℃以上へ暖機/循環 or 冷態は40メッシュ or 低流量起動。

## 3. 未確定・要検証
- **下流圧（タンクヤード側）1点**でΔP_CVを実測確定（今は逆算＋2014モデル整合）。
- **低温ΔP∝μは層流前提の上限評価**。起動低流量(ΔP∝v)で緩和。実機は差圧直読で確認。
- **FC-1531の現行Cv値**（14 vs 2014の10/21）を確定。
- ΔPがRと弁特性に過敏：理想等％でなく**実測アンカー（開度→実Cv）**で計算すること。

## 4. 経緯（誤り→修正の記録）
- CV差圧を 1.2→550→340→411kPa とブレさせた。**原因＝別弁(FC-1535の1.2kPa)・設計指標(50/60kPa)・理想R=50逆算(過大)を同じ土俵で混同**。実値は数百kPa(340–424)で一貫、と判明。
- フロー誤認（FC-1531はE-1509下流／FC-1535は別圧点）を修正。「両弁が同一ヘッダ圧」という私のクロスチェックは無効として撤回。
- 「FC開度で閉塞監視」(pptx)は数字で見ると**感度不足で主指標にできない**と判明 → 差圧直読を主に格下げ。
- 物性は「単位付き適当数字」でなく**Aspen物性ツールの式＋温度振り表/グラフ**で妥当性を見せる方針に変更（本記録の§1.5式）。
- Excelは**前提条件シートから引かず、各シート（NPSH/差圧/CV/低温）で考え方＋必要入力＋計算を完結**させる方針に変更。

## 6. 統合(v2) — 計算/批評エージェントの結果反映（2026-06-18）

### 計算エージェント（独立再計算）
- Aspen物性式で 158.8℃ → μ=1.164cP / ρ=1010 / Pvp=5.5kPa＝**検証一致**。式の解釈は正しい。
- (a)限界ΔP=116.9kPa (b)250クリーン3.56kPa (c)低温20℃→116.4kPa(残余0.5) (d)**CV ΔP0=411kPa・開度+5.0%**。
- 弁式係数の単位：`0.0865(ΔP=kPa) ＝ 0.865(ΔP=bar)` で同値。どちらでも411kPa（混同注意）。

### 批評エージェント（独立レビュー）
- **確定してよい（頑健）**：「FC開度は監視の主指標にできない／主指標＝ストレーナ差圧直読」はS/N比<1で堅い。取り違え整理(§4)も妥当。
- **要修正（v2で反映済み）**：
  1. NPSH「117kPa＝即キャビ」→「**余裕喪失**」へ表現修正。NPSHa基準面・運転点NPSHr・安全余裕は★要確認。
  2. CV ΔP=411kPaは**実測1点依存の推定**。上限500の算術根拠は弱い。→ 下流圧1点実測で1値に確定（最重要）。
  3. 運転開度30%は実測アンカー(59〜70%)の**外側＝外挿**。現行Cv定格(14 vs 2014の10/21)＋30%実Cvを要確認。
  4. 低温は『定格流量×完全層流×定常NPSH』の**最悪上限**。起動低流量(ΔP∝v)＋低温でPvp激減→NPSHa改善。→ **条件付きに格下げ（v2反映）**。
