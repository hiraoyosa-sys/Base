# 感触（先出し・結論）

**「ホルムダウン ⇒ 有機酸ダウン ⇒ 腐食抑制」は、向き（化学）は正しいが、
いま議論しているホルムパージ（C-1303 TOP回収先変更）を "腐食対策" として出すのは、現データでは成り立ちにくい。**
ただし **"腐食対策" ではなく "不確実性への保険（バックアップ）＝配管手当だけ先行で残す"** なら成り立つ。
これは木村さんが既に持っている見立て（「設備として織り込むが使わなければよい」方向）と同じ着地。

- 主対策はあくまで **リン酸Na＋材質更新**。ホルムパージはその上に載せる保険。
- 朝会では **"腐食を抑える対策"** と言い切らない。**"腐食リスクの不確実性が残る間、選択肢を潰さないための保険"** と正確に言う。
- RDの7/1結論（ホルムの色相寄与は限定的）を否定せず、別軸（腐食）で、かつ効き所を正直に絞って立てる。

# 動かない事実（実データで向きが確定していること・先に置く）

1. **腐食性ギ酸の主生成は上流＝EO反応器〜EO吸収塔配管。42℃のEG反応器ではない。**
   不純物マトリクス ギ酸(FAC)行：主生成箇所「EO反応器〜EO吸収塔配管」／機構「F-ALD酸化(HCHO→HCOOH)・Fe₃O₄触媒」／持込経路「EO吸収塔→EG系(ブリード経由)」。
   酸化の条件は反応機構カタログ「Fe₃O₄触媒(鉄錆)・O₂存在」。EG反応器の実条件は「R-1401・約42℃・0.2MPaG」＝**錆＋O₂＋高温と逆向き**。

2. **EG系に届くホルムは既に微量で、源はもう絞られている。**
   PJ 7/1定例3.2節：「F-ALD＝EO反応器で約1 kg生成・EO吸収系の水和で約9割除去・**EG系原料到達は約0.1 kg**。2018年にEO熱交換器をチタン材化しホルムを貯めない運転に変更→以降ホルム低下」。

3. **ギ酸を実際に下げたのはリン酸Na。ホルム低減ではない。**
   PJ 2026-07-04：「脱水塔BTMギ酸 6〜7→2.6〜3.1ppm（リン酸Na 5%水溶液1L/h連続投入・2026/4/20〜で低下）」。

4. **過去の腐食の引き金は鉄錆であって、フィードのホルム高ではない。腐食の場は高温濃縮部。**
   1998鹿島：「H10定修時鉄錆↑→ EO系ギ酸生成1.3倍増→ MEG塔TOP蟻酸濃縮→ SUS304腐食→ Ni²⁺溶出」。
   2019：「DEG塔BTM減肉｜気相部で有機酸(蟻酸)濃縮→ CS腐食」。

5. **いま、実肉厚に有意な腐食は出ていない。**
   PJ 6/19：「肉厚測定記録を整理中（原肉に対して有意な減少なく問題なし）」。
   PJ 6/23：「定点の肉厚測定（CM153等）＝横ばい・微増・微減が混在・1mm程度の変動を実腐食と断じるか測定誤差とみなすか容易でない」。

6. **EG系原料水では、ホルムが高くても有機酸は検出下限以下。**
   docx Ⅷ-2：「EG系原料水では A-ALDは11〜24ppmと高いが、有機酸は検出下限以下」。
   pH-有機酸バランス EG原料水：AALD=23ppm/FALD=4ppm でも グリコール酸<3・乳酸<4。

# 「ホルムダウン⇒有機酸ダウン⇒腐食抑制」の判定

## 成り立つ所（フェアに認める部分）
- **入口の一段目は化学的に正しい**：ホルムはギ酸の直接前駆体（HCHO→HCOOH、Fe₃O₄触媒）。ギ酸＝ホルム由来、酢酸＝アセト由来。主要有機酸のギ酸はホルム由来。
- **出口も実在**：ギ酸は腐食性で前科あり（1998 SUS304腐食→Ni溶出、2019 DEG塔BTM減肉）。「ギ酸ダウン⇒腐食抑制」の向きは過去トラで裏打ち。
- **腐食は色相と別KPI**：腐食性で効くのはギ酸（ホルム由来）で、色相主因（RD説＝アセト×Na）とは化学軸が別。**色相論争を回避して別土俵に立てる余地は原理上ある。**
- **チームは既にこの筋を評価済**：PJ 6/23で「設備腐食ストーリー＝アルデヒド高濃度→有機酸(ギ酸)生成→腐食懸念→点検、が現実的かつ説明容易」と評価。ゼロからの思い付きではない。

## 成り立ちにくい所（最強の反論・ここが詰み筋）
**介入点（C-1303 TOP回収先変更）が、腐食に効くギ酸の生成箇所より下流にある。だから、この案をやっても腐食性ギ酸はほとんど減らない。**
- 腐食性ギ酸は上流（反応器〜吸収塔）で既に生成し、**液相のブリード**でEG系に入る。C-1303 TOP回収先変更が触るのはEO精製塔頂の**蒸気側**だけ＝ブリードのギ酸には手が届かない。
- 量も小さい：抜けるのはEG到達ホルム約0.1 kg/h相当。全量ギ酸化しても有機酸4 kg/hの**数%以下**。しかも酢酸（A-ALD由来）は残る。
- 中段リンクの実測が無い：EG系原料水で有機酸は検出下限以下＝**EG系内でホルム→ギ酸が有意に新規生成している証拠が一次情報に無い**。
- 守るべき実害がまだ無い：肉厚「有意な減少なく問題なし」。腐食対策の本命はリン酸Na＋材質更新。

# 残すなら＝「腐食対策」でなく「保険（バックアップ）」で

木村さんの既定見立て（「設備として織り込むが使わなければよい」／流量~500kg・配管短・EOエリア内・影響小・CV確保）と、7/1テスト計画の「予算は配管手当のみ先行（修繕費）も選択肢」に沿う形。生かすなら次の3条件をすべて満たす。

1. **"腐食を抑える対策" ではなく "腐食リスクの不確実性への保険" と言う。**
   いま腐食は起きていない（肉厚問題なし）。「対策」と言い切ると実証減肉データを求められて即崩れる。

2. **効き所を「EG系内での新規ギ酸」に自分から限定し、上流由来・ブリード由来には効かないと認める。**
   これは自動的に「効き代は有機酸の数%＝保険の域」を認めることになるが、そう言えば下流論者に足を取られない。

3. **降ろせない理由＝ホルム供給量とEG系内ギ酸生成が未確定。**
   PJ nightly⑳：「ホルム設計前提150 g/h vs 一部運転実績で約700 g/h観測」。実ホルムが想定より多い可能性が残る間は、配管手当だけ先行で選択肢を残す。

**言い回し（7/3草の根メモの核をそのまま使うのが安全）**
「ホルム対策を残したくて残すわけじゃない。説明しきれない不確実性（実ホルム量・EG系内ギ酸生成）が残っている間だけ、**配管手当で選択肢を残したい**。説明がつけば安心して外す。」
→ RDのどちらの返答でも面子が潰れない設計。RD結論（ホルム影響薄い）を否定しない。

**危ないパターン**：そのまま「腐食抑制対策」として朝会に出すと、RDから「除外した色相対策を看板だけ貼り替えて復活させただけ」と読まれ、7/1で取った合意ごと信用を落とすリスク。

# 基礎研（RD）に投げる検証項目トップ3（朝会スライド「基礎研で検証してもらう項目」用）

1. **濃縮ギ酸の起源切り分け**：MEG塔TOP・脱水塔BTM・DEG塔BTM気相の濃縮ギ酸を、①上流（反応器〜吸収塔）由来のキャリーオーバー分と、②EG系内でホルムから新規生成した分に物質収支で分離。**C-1303 TOP回収先変更で減らせるのは②だけ**なので、②が全体の何%かを数値で。（1998鹿島のMEG塔TOP=45ppmは①＝上流由来）

2. **EG系実条件でのホルム→ギ酸酸化のラボ確認**：42℃・脱気・微量O₂リーク・残存鉄サビ共存下で有意速度で進むか。「EG原料水で有機酸は検出下限以下」との整合を取り、EG系内で消せるギ酸生成量の**上限**を出す。

3. **リン酸Na連投下でのホルムパージ追加分の限界効用**：リン酸Na＋材質（SUS430・セラミック溶射）で腐食が足りるのか、ホルムパージ固有の便益が残るのかを、1998で実績のインピーダンス法腐食速度で定量比較。あわせて宿題①（4kg/1kg/0.1kgのアルデヒドバランス）を有機酸内訳（ギ酸:酢酸:グリコール酸:乳酸）まで拡張し、ホルム由来ギ酸の絶対量を確定。
