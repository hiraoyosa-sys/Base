## 1. 宿題① オフスペックタンク（オフタンク）の必要容量 再整理

**指摘の要点**
- 分析時間を含めた再整理が必要。
- 「580 tでいいですか」ではなく、**超えた場合どうするかまで込みで握る**のが「握る」ということ。

**現状の整理**
- 分析時間 3時間込みで回しても、**200 t 空いていれば捌ける**見込み。
- タンク上限 580 t に対し、事前に **380 t 以下まで下げて 200 t 確保** する（これはSAの内容から変更なし）。
- ただし計算がぴったり580 tで、余裕がほぼない = **今の速度でギリギリ間に合うか否か**。

**やること**
1. 分析時間（3 h）を織り込んだ時間ベースの積み上げを作り、200 t で足りる根拠を見える化する。
2. **超過時の逃げ道を明記して合意する** → 例: 超えた分はブリードタンクへ受ける。
   「超えるかもしれないがいいですか」ではなく「超えた場合はブリードで逃がす。その前提でよいか」の握り方にする。

## 2. 宿題② テスト時の運転条件の明確化（最重要／資料の根本問題）

**指摘の要点**
- 資料の表が **操作系（自分で設定するもの）と結果系（その結果として変化するもの）が混在** しており、
  表が肥大化して読めない。これが「運転条件が見えない」というコメントの正体。
- 「目標値」「設定値」「閾値」の言葉の定義が揺れている。

**分けて書くべき3層**

| 区分 | 定義 | 本テストでの中身 |
|---|---|---|
| 目標値 | 達成したい状態 | **C-1501 ボトム温度 167 ℃** |
| 操作（設定値） | テストのために通常と変えて設定する項目 | 塔頂圧力 **23 kPa に固定**／ボトム抜き出し流量 FC-1501 の調整 |
| 影響（結果）要因 | 操作の結果として変化するもの・監視するもの | 水バランス、排水バランス、原料バランス、製品バランス、DEG/MEG 濃度、弁開度(MV) |

**運転の考え方（合意された整理）**
- 圧力は **23 kPa 固定**。コンデンサに余裕がない前提で設計値を23 kPaとしているため、
  実運転で下げしろがあっても下げない（22 kPaでテストしたら23 kPa設計の妥当性が崩れる）。
- 167 ℃ は **FC-1501 のボトム抜き出し流量（開度）で合わせにいく**。抜き出しを増やす → ボトムのMEG濃度が上がり温度が下がる。
  ただしやりすぎると出口側MEGが増えるので、**製品出口のMEGを見ながら少しずつ**。
- TC設定（DEG塔側含む）は **変更しない前提**。
- MEGリサイクルを増やすとDEG生成が増えるので、それに応じて抜き出しを上げていく＝**通常のロード調整と同じ操作**。
  今回と通常運転の違いは「圧力を固定したこと」と「167 ℃という目標値を置いたこと」だけ。

**閾値／逸脱時の扱い（資料に明記する）**
- 23 kPa まで下げても 167 ℃ に到達しない場合 → **その状態でステイ**（それ以上は設計外・未評価のため）。
  テスト中止ではなく、その条件でテストを実施する。
- MV（弁開度）が下限 20 % を下回る恐れがある場合 → 下回らない圧力で固定する。
- DEG品質は何 ppm まで許容し、その時に何 t ずつ抜き出しを調整するか、という**操作の刻みを書く**。

**やること**
- 上表の3層に分解した運転条件表を作り直す（明日午前）。
- EG原料水バランス・還流量など「結果としてどうなるか」の見通しを、操作系とは別表で示す。

## 3. 宿題③ タンク604（DEG）のホールド期間

**論点**: 品質保証（小林さん）から **6日 → 8日に延ばせないか**。

**回答**: 延ばせない。
- ネックはタンク容量ではなく **SPタンクへの移送タイミング（8/11）**。盆明けは日程が詰まっており、
  ずらすと後ろのテストが実施できなくなる。

**定義の整理（資料に明記）**
- ホールド起算 = **タンク604のミニマム在庫（60 t）到達時点を0日**。以降は張り込み継続中でもホールド扱い。
- 8/4到達 → 8/5起算 → 8/11送出 = 6日間。

**指摘された弱さ**
- 「期日がないからできません」は回答として弱い。**代替で担保できるから6日でよい、という組み立てにする。**

**代替案の検討結果**
- ボンベ（取り置き）サンプル: 現状 **3本しかなく**、今回の計画には入っていない。
  ストリーム品のボンベとタンクは基本的に同傾向であることが確認済みのため、追加取得のハードルは高い。
  → **鈴木さんには「言うだけ言ってみる」**スタンス。
- 8日案の狙いは、タンク555/615でUV450がやや上昇する傾向を踏まえ、標準品判断の確度を上げたいというもの。

**やること: タンク604の内訳の見える化**（「これは極めて簡単なのでやる」と合意済み）
- 稼働調整開始 → テスト → 正常状態復帰までの、どこからどこまでがタンク604に入るのかを分解。
  - 前品（配管ホールドアップ）: 約4 t
  - テスト期間分: ○ t（要記入）
  - 移行品: ○ t（要記入）
  - **合計 ○ t の山として評価します**、という書き方にする。
- 「この期間は何、この期間は何」と期間ごとの内訳を明記する。

**現状**
- 東レ向けには送らないケアをした上で、余る2基のタンクにテスト品を張り込む計画。
- 追加案として **タンク1501（CD、500 t強、現在空）** を一次受けに使えないか検討中。
  - 運転操作としては実施可能（変更にはならない）。使うかどうかは**物流・ビジネス判断**。
  - タンク余力が増える方向なので **使えるならそちらがプリファー**。

  **クリティカルパスがどこか／最後の希釈は別タンクで持つ等の分解案**まで示して議論できる状態にする。

**運用イメージ（案）**
